# Scripts para Chatwoot

Scripts prontos para uso em sua instalação do Chatwoot que adicionam funcionalidades extras.

## Requisitos

- [Chatwoot 4.X.X](https://infotecmg.net/) - Soluçãos completas para Chatwoot

## Como Instalar

### Método Correto de Instalação

1. Acesse sua instalação do Chatwoot com uma conta de super admin
2. Navegue até `https://seuchatwoot.com/super_admin/app_config?config=internal`
3. Cole o conteúdo do script no campo "Dashboard Scripts"
4. Role até o fim da pagina e salve
